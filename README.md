## Comunidade Samuel Maggi

**Uma simulacao didatica de urna eletronica, desenvolvida em Python com Pygame.**

O projeto demonstra a construcao de uma interface grafica interativa,
utilizando eventos, botoes, entrada numerica, estados e validacao de dados.

## Como instalar

### 1. Clone o repositorio

```bash
git clone https://github.com/samuelcmaggi/urna-eletronica-python.git
cd urna-eletronica-python
```

### 2. Instale as dependencias

```bash
pip install -r requirements.txt
```

### 3. Execute o projeto

```bash
python urna.py
```

No Windows, utilizando Python 3.13:

```powershell
py -3.13 urna.py
```

---

## Como utilizar

1. Abra o programa.
2. Utilize o teclado numerico para informar a opcao de teste.
3. Use CORRIGE para apagar a entrada.
4. Use BRANCO para testar a simulacao de voto em branco.
5. Use CONFIRMA para confirmar a escolha.

Os numeros disponiveis sao definidos pelo codigo do projeto.
